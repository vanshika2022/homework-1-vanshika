# Homework 1
## Due date: 2026-02-15

Once the assignment link is accessed, you will automatically be able to access your individual version of this repository.

### Students are required to do the following steps in order to get full credit:
1. Clone the repository to your local machine.
2. Identify yourself: Open the `Identify.txt` file and enter your name, netid, N-number and NYU email address (so we link your Github account with Brightspace)
3. Add/move files:
    1. Create a new file named `hello-world.txt` and commit it to the repo.
    2. Create a new directory named `Hello` and move `hello-world.txt` into that directory.
    3. Write a message for the grader in the hello-world.txt file
    4. Finally commit the changes in the previous step.
4. Delete files:
   1. There is a folder "wrongFork" that contains three files that was created erroneously. 
   2. Delete both the folder and the files in it from your repository.
5. Branching:
    1. Create a new branch of the repository.
    2. Edit the file `V.txt` answering the question asked in that file.
    3. Commit the changes and merge that branch into the main branch.

### Notes:
1. Please make sure to follow the instructions in the README.md file exactly as provided, as we'll be looking at the git log file for grading the assignment.
2. Your NYU NetID is usually your initials followed by numbers (e.g., pw44).  It is *not* your N-number - the N number is a long number after the N (usually on the back of your NYU ID)
3. This is an individual assignment, to be completed by each student separately.
4. This goes without saying but we are saying it here anyway because people have lost points in the past: When you do something, make sure to commit the change. Otherwise, it won't take. For fairness, we will grade the assignments in the state they are in at the due date. We can't grade intent. Make sure to commit.
5. It is important to use descriptive commit messages whenever you make a commit. This is one of the things that will be considered while grading. Try to make them concise, clear, specific and descriptive.
6. Note that Github doesn't really have a concept of folders per se. Everything is file based. Keep that in mind for the assignments above that involve folders.
7. Please make sure to upgrade to the latest version of [git](https://git-scm.com/) (at least version 2.39.1).
